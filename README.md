# WattBox 300

Individual outlet switches plus read-only outlet states, voltage, current, and total power sensors for the WB-300VB-IP-5.

## Installation

Use [HACS](https://hacs.xyz), or download the latest [release](https://github.com/josh/homeassistant-wattbox-300/releases/latest) and copy `custom_components/wattbox_300` into your `config/custom_components/` directory.
